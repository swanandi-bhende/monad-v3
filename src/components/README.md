# Components

Reusable React components. Client components start with `"use client"`.

- `ui`: generic presentational primitives such as buttons, badges, and cards.
- `bounty`: bounty cards, status badges, and reward display.
- `submission`: submission rows and credibility controls.
- `forms`: form controls and field wrappers for the post and submit flows.
- `layout`: header, navigation, and the network banner.
- `providers.tsx`: client-side providers (wagmi and React Query) wrapped by the root layout.
