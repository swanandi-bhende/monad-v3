# Constants

Static values shared across the app.

- `network.ts`: the single source of truth for the Monad Testnet chain, RPC, and explorer.
- `tokens.ts`: the reward token address, symbol, and decimals.
- `bounty.ts`: categories, selection methods, and status labels.
- `abi.ts`: exports `PROOFBOUNTY_ABI`, generated by `npm run abi:sync` from the Foundry build. Do not edit by hand.
